##  Objetivo

Este repositório tem como objetivos principais:

1. **Organizar** todo o conteúdo estudado durante o curso
2. **Documentar** o processo de aprendizado
3. **Compartilhar** conhecimento com outros estudantes
4. **Criar um portfólio** acadêmico completo
5. **Facilitar a revisão** de conceitos importantes

## Como Utilizar

1. **Navegue** pelas pastas correspondentes aos anos e disciplinas
2. **Consulte** os materiais de estudo organizados por tópico
3. **Contribua** se encontrar erros ou tiver sugestões (issues são bem-vindas!)
4. **Use como referência** para seus próprios estudos

## Notas Importantes

- Este repositório está em **constante atualização** conforme meu progresso no curso
- Os materiais incluem: anotações, exercícios resolvidos, projetos, resumos e recursos externos
- Algumas pastas podem estar vazias inicialmente - serão preenchidas ao longo do tempo

##  Contribuições
